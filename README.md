The AI-Based Disease Recommendation System is a web application designed to provide personalized health recommendations based on the disease selected by the user and its severity level. The system guides users through a simple multi-page interface where they can choose a disease, specify its level (Mild, Moderate, or Severe), and receive tailored precautions along with recommended foods to help manage their condition.

Features
Disease selection interface.
Severity level selection (Mild, Moderate, Severe).
Personalized health precautions.
Recommended food suggestions for each disease and severity level.
Interactive multi-page navigation.
User-friendly and responsive design.
Diseases Supported
Blood Pressure (BP)
Diabetes (Sugar)
Thyroid
Technologies Used
HTML5
CSS3
JavaScript
Project Workflow
Select a disease.
Choose the severity level.
View personalized precautions and food recommendations.
Improve awareness of healthy lifestyle choices.
